**一句话定位**

把任意 HTML 拖进浏览器，**点哪里改哪里，导出即用**，不需要本地 dev server，也不用 DevTools 与源码来回抄。

---

## 🔗 极简链路 
**导入 HTML → 点选修改 → 导出 HTML**

三步完成页面精修，工作流短、无环境依赖、无上下文切换。

---

## ❌ 以前 vs ✅ 现在 
| 场景 | 以前 | 现在 |
| --- | --- | --- |
| 改一个按钮颜色 | Elements 面板 + IDE 来回试 | 点选 → 侧栏改色 → 立刻可见 |
| 改课件 / 活动页文案 | 找前端改源码 | 双击改字，或指令栏输入 |
| 换图片 | 改 `src`，还要担心脚本硬编码 | 侧栏上传，导出自动替换 |
| 评审调间距 | 口头描述难对齐 | 滑块调节，当场预览 |


---

## ✨ 核心体验 
+ **拖拽即用**

任意 `.html`拖进浏览器即可编辑，无需构建、无需服务。

+ **所见即所得**

在真实渲染页面上操作，修改即时呈现，贴近最终交付效果。

+ **说人话也能改**（非 AI，规则引擎）

指令栏支持中英文自然语言，例如：

「字号加大」「背景改成主色」「圆角 8px」

「文字改成：欢迎参加本次活动」

+ **改完能带走**

一键导出干净 HTML（含样式与媒体），可直接交付或上线。

---

## 🧠 核心能力（已上线） 
### 导入即编辑 
+ 本地 HTML 拖放 / 粘贴整页源码
+ 内置 **全功能演示页**，开箱体验 Flex / Grid / 媒体 / 网络面板

### 所见即所得编辑 
+ 图层树 + 画布点选，支持 `Ctrl`多选
+ 设计 Token 色板、取色器、间距滑块
+ Flex / Grid：九宫格对齐、行列滑块、画布参考线
+ 双击改字，结构模式下拖拽重排

### 调试一体化 
+ 底栏实时展示 **Console + Network**
+ 改页面的同时排查资源加载问题

### 导出与协作 
+ 导出 HTML（`Ctrl + S`），包含当前预览状态
+ 撤销 / 重做，变更 Diff 可追溯
+ （可选）将部分变更写回 monorepo 源码，适配研发流程

## 🚀 30 秒体验路径 
### 本机体验 
```plain
npm install
npm run build:runtime
npm run dev
```

浏览器访问：http://localhost:5174

→ 点击「打开全功能演示」

→ 点选标题 → 右侧改色 / 双击改字

→ 顶栏「导出 HTML」→ 用浏览器打开下载文件

### 测试环境（已部署） 
访问：`https://{你的域名}/visual-editor/`（按实际 nginx 配置）

无需观众本机安装 Node。

## 🆚 和常见方案的区别 
| 方案 | Visual Editor | 说明 |
| --- | --- | --- |
| Figma / 画板 | 编辑**真实 HTML**（含脚本、字体、DOM） | 不是静态稿 |
| 浏览器 DevTools | 提供设计向控件、图层树、导出与撤销 | 不止临时修改 |
| 本地 dev 预览 | 仅导入 HTML，免跨域与白屏 | 面向交付物 |
| Cursor Browser 等 | 同类方向；我们聚焦 **HTML 导入闭环 + 课件场景** | 非替代关系 |

## 🔒 可信度与边界 
+ iframe 与外壳通过 **postMessage 协议通信**，变更可追踪、可撤销
+ 导入页面为 **会话级内存托管**，导出才落盘
+ 已支持内网域名、子路径反代，`ve-runtime.js`可独立构建
