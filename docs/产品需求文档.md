## 2. 执行摘要

**一句话**：导入网页 → 点选改样式 / 文字 / 媒体 → 导出 HTML 即可交付。

Visual Editor 是面向课件、活动页等 **成品 HTML** 场景的可视化编辑器：用户通过浏览器上传或粘贴 HTML，在真实 DOM 上编辑，主路径为**导出 HTML**；可选将变更 Diff 写回 monorepo 源码或嵌入 VS Code Webview。

**核心差异**：不连接本地 dev server，避免跨域、代理与白屏；预览区为 iframe 内真实页面，非静态 mock。

## 3. 问题与机会

### 3.1 现状痛点

| 痛点 | 影响 |
|------|------|
| 调样式依赖 DevTools + 源码往返 | 反馈慢，非工程师难以参与 |
| 成品 HTML 改文案 / 换图成本高 | 依赖开发排期 |
| 评审「再大一点」「主色再亮」难以当场呈现 | 沟通与返工多 |
| 连接 dev URL 预览 | 跨域、代理、环境不一致导致不可用 |

### 3.2 产品机会

在**不改变原有构建链路**的前提下，提供「导入 → 可视化改 → 导出」闭环，让前端、设计、产品在同一页面上快速迭代并交付可运行的 HTML 文件。

## 4. 产品目标与非目标

### 4.1 目标（Goals）

| ID | 目标 | 可验证结果 |
|----|------|------------|
| G1 | 降低 HTML 页面视觉/文案调整成本 | 用户无需打开 IDE 即可完成常见样式与文字修改 |
| G2 | 保证「所见即所得」 | 导出 HTML 与编辑预览一致 |
| G3 | 支持内网部署与演示 | Docker + nginx 子路径可稳定访问 |
| G4 | 为源码协作留扩展 | Diff 预览 + 可选写回 `fileMap` 配置路径 |

### 4.2 非目标（Non-Goals）

| 项 | 说明 |
|----|------|
| 替代 Git / IDE | 不提供完整工程管理与分支能力 |
| 连接任意 dev server URL | 已移除；仅 HTML 导入 |
| AST 级全站重构 | 当前为 DOM 会话编辑 + 字符串 patch |
| LLM 自动改代码 | 指令栏为规则 NLP；LLM 接口预留 |
| 多租户 SaaS / 协作编辑 | 不在当前版本 |
| 导入会话永久存储 | 内存 import-store，TTL 24h |

## 5. 目标用户与场景

### 5.1 用户角色

| 角色 | 典型任务 | 成功标准 |
|------|----------|----------|
| 前端 / 课件工程师 | 改布局、颜色、文案、媒体地址 | 5 分钟内完成导入并导出 |
| 设计师 | 在真实 HTML 上微调视觉 | 不破坏页面自有主题与 Token |
| 产品经理 | 指令栏描述样式/文字意图 | 规则可解析的意图当场生效 |
| 运维 / 内网用户 | 部署测试环境、排错 | 健康检查通过、核心路径可演示 |

### 5.2 典型场景（Jobs to be Done）

| 场景 | 触发 | 期望结果 |
|------|------|----------|
| 课件微调 | 收到完整 `.html` | 改色、改字、换图后导出交付 |

| 评审演示 | 评审会现场改样式 | 指令栏 + 侧栏即时预览 |
| 与仓库对齐（扩展） | 页面来自 monorepo | Diff 后写回 `demo-app` 等配置路径 |

## 6. 产品范围

### 6.1 版本范围（当前 v1.0 基线）

| 模块 | 包含 |
|------|------|
| 接入 | 连接页：本地文件、粘贴 HTML、全功能演示 |
| 工作台 | 图层树、iframe 画布、设计/CSS 侧栏、指令栏、面包屑、调试区 |
| 编辑 | 样式、Flex/Grid、文字、媒体、Props、结构拖放、规则 NLP |
| 调试 | 控制台同步、网络请求只读 |
| 交付 | 导出 HTML、撤销/重做、变更 Diff、可选写回源码 |
| 嵌入 | VS Code Webview 插件 |
| 部署 | Node 服务 + Docker + nginx 子路径 |

### 6.2 假设与依赖

| 类型 | 内容 |
|------|------|
| 假设 | 用户提供合法 HTML；主要浏览器为 Chromium 系 |
| 依赖 | Node 20+ 运行时；`ve-runtime.js` 由服务端提供 |
| 可选依赖 | OSS 上传需配置 `VE_TOOL_TOKEN`；写回需 `.visualeditorrc.json` 的 `fileMap` |

### 6.3 范围外（明确不做）

| 项 | 处理策略 |
|----|----------|
| 导入页随 Shell 改配色 | 默认禁止，避免覆盖页面 `[data-theme]` |
| Diff 写回 = 保存导入页 | 导入页用**导出 HTML**；写回针对 monorepo |
| 仅静态托管 `dist` | 不支持；须 Node API |

## 8. 用户故事与验收标准

验收格式：**Given** 前置条件 → **When** 操作 → **Then** 可观测结果。  
优先级：**P0** 阻塞发布 / **P1** 核心体验 / **P2** 增强。

### 8.1 导入与预览

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-01 | P0 | 作为用户，我上传或粘贴 HTML | **Given** 连接页 **When** 选择 `.html/.htm` 或粘贴并导入 **Then** 进入工作台且 iframe 完整显示页面；非法格式有明确错误 |
| US-02 | P1 | 作为用户，我打开全功能样例 | **Given** 连接页 **When** 点击「打开全功能演示」 **Then** 导入 `fixtures/ve-feature-test.html` 且树与点选可用 |

### 8.2 可视化编辑

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-10 | P0 | 点选元素改样式 | **When** 在设计/CSS 侧栏修改 **Then** 画布 ≤100ms 级更新；支持 Token 色板、ColorPicker、间距滑块 |
| US-11 | P1 | Flex / Grid 布局 | **Given** `display:flex\|grid` **When** 使用专区块 **Then** 对齐/列行/gap 生效且画布有布局参考线 |
| US-12 | P0 | 改文字 | **When** 双击画布、侧栏文本或指令栏 **Then** 文本更新且可撤销/重做 |
| US-13 | P1 | 改媒体 | **Given** img/audio/video **When** 改 src 或 OSS 上传 **Then** 预览更新且导出含新 URL |
| US-14 | P2 | Props | **Given** `data-ve-props` **When** 改动态表单 **Then** 画布即时预览 |
| US-15 | P1 | 结构模式 | **When** 同级拖放重排 **Then** 树与画布顺序一致 |
| US-16 | P1 | 自然语言 | **When** 指令栏输入中英文样式/文字意图 **Then** 规则引擎解析并应用（非 LLM）；无选中时有提示 |

### 8.3 调试与主题

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-20 | P1 | 查看控制台 | **When** 目标页输出 console **Then** 底栏同步显示；error 计入角标 |
| US-21 | P1 | 查看网络 | **When** 页内 fetch/XHR/资源请求 **Then** 网络 Tab 只读列表含状态与耗时 |
| US-22 | P1 | 切换编辑器主题 | **When** 顶栏切换浅/深色 **Then** 仅 Shell 变化；导入页默认不改变预览区内配色 |

### 8.4 持久化与交付

| ID | 优先级 | 用户故事 | 验收标准 |
|----|--------|----------|----------|
| US-30 | P0 | 导出 HTML | **When** `Ctrl+S` 或顶栏导出 **Then** 下载文件内容与当前预览一致（含 NLP/侧栏改动） |
| US-31 | P0 | 撤销重做 | **When** `Ctrl+Z` / `Ctrl+Y` **Then** 样式、文本、媒体恢复 |
| US-32 | P1 | 变更 Diff | **Given** 有待应用变更 **When** 打开 Diff **Then** 并排对比；导入页为 `imports/{id}.html` 语义 diff |
| US-33 | P2 | 写回源码（可选） | **When** 勾选文件并应用 **Then** 写入 `fileMap` 路径；**不**自动重载 iframe |

### 8.5 端到端验收场景（E2E）

| ID | 场景 | 通过条件 |
|----|------|----------|
| E2E-01 | 冷启动导入 | 导入 → 5s 内可点选 → 改样式 → 导出 → 单独打开 HTML 一致 |
| E2E-02 | 全功能演示 | 演示页 → Flex/Grid/媒体/网络/指令栏均可操作 |
| E2E-03 | 主题隔离 | 切换 Shell 主题后导入页内颜色不变 |
| E2E-04 | 部署可用 | `/api/health` ok；`ve-runtime.js` 200；图层非空 |

## 9. 业务规则

| 规则 ID | 规则 | 说明 |
|---------|------|------|
| BR-01 | 主交付为导出 HTML | pending 为会话级；导出前画布已预览 |
| BR-02 | 导入大小上限 5MB | 超出拒绝并提示 |
| BR-03 | 上传上限 30MB | OSS 代理限制 |
| BR-04 | 写盘沙箱 | `/api/apply` 仅允许 `demo-app/` 下路径 |
| BR-05 | 导入会话 TTL 24h | 进程重启或过期需重新导入 |
| BR-06 | 有 importId 时主题不同步预览 | 见 US-22；联调页可 `data-ve-allow-shell-theme` |

## 10. 非功能需求（NFR）

| 类别 | 要求 | 验收方式 |
|------|------|----------|
| **性能** | 侧栏改样式后画布即时反馈；图层树更新防抖约 120ms | 人工 / 计时抽样 |
| **性能** | 导入到首次点选 < 5s（含 runtime） | E2E-01 |
| **可用性** | 测试环境目标 99%（内网工具） | 部署健康检查 + 重启策略 |
| **安全** | postMessage origin 白名单 | 非白名单域消息被忽略 |
| **安全** | 写盘路径沙箱、上传/导入大小限制 | API 测试 |
| **安全** | OSS Token 仅服务端 | 浏览器无 `VE_TOOL_TOKEN` |
| **部署** | 须 Node 提供 `/api/*` 与 runtime | 禁止仅静态 `dist` |
| **部署** | 支持 `VE_BASE_PATH` 子路径 | nginx 反代联调通过 |
| **兼容** | 现代 Chromium；Node 20+ | 文档与环境矩阵 |
| **可维护性** | 用户故事 ID 与文档可追溯 | PRD ↔ 交互原型 §4.2 |

## 12. 风险与开放问题

| 风险 | 影响 | 缓解 |
|------|------|------|
| 导入 HTML 含恶意脚本 | 内网 XSS | 工具定位内网；用户自担导入内容 |
| 会话内存丢失 | 重启后需重导 | 文档说明；未来 Redis 持久化 |
| 课件内联脚本覆盖样式 | 导出与预览不一致 | 导出固化变量 + pending patch |
| 仅静态部署 | 功能全挂 | PRD + 用户手册强调 Node 部署 |

| 开放问题 | 状态 |
|----------|------|
| LLM 指令栏接入方式 | 待定；保持 `SemanticChange` 协议 |
| 多文件站点导出格式 | backlog P2 |
