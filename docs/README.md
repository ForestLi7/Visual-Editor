## 维护约定

1. **行为或验收变更** → 先改 PRD，再同步交互原型与用户手册。
2. **实现或协议变更** → 同步技术方案。
3. **对外分享口径** → 更新 [产品宣传与分享](./产品宣传与分享.md)；细节以 PRD / 用户手册为准。
4. **勿在 `docs/` 下新增零散 md**；其余内容写入上述文档之一。
